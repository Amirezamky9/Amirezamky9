## 📦 Featured Projects

### [n8n Teacher Bot + WorkflowYab](https://github.com/Amirezamky9/n8n-teacher-bot)

**Multi-mode Telegram bot** built entirely in **n8n** — an AI teacher for learning n8n and a semantic WorkflowYab search engine.

- Three modes: Teacher (AI tutor in Persian), WorkflowYab (RAG workflow search), Debug (n8n debugging)
- **MCP integration** for searching n8n nodes, documentation, and workflow templates
- **PostgreSQL memory** with conversation history and email OTP authentication
- Uses OpenAI, Gemini, and Groq LLMs with rate limiting
- Complete node inventory, data flow diagrams, and database schema documented

*Tech: n8n · AI Agents · MCP · PostgreSQL · Telegram API · LLMs (OpenAI, Gemini, Groq)*

---

### [Crypto Ingestion Pipeline](https://github.com/Amirezamky9/crypto_ingestion_pipeline)

**On-demand, webhook-triggered OHLCV ingestion service** — fetches candlestick data from KuCoin and upserts into PostgreSQL.

- **FastAPI** service with Bearer token security
- Smart delta + backfill strategy, gap-healing overrides
- **Zero DDL** — only uses existing `candles` table
- **Zero disk logs** — all logs stream to external webhook
- Exponential backoff retry on transient failures (`429`, `5xx`, timeouts)
- Candle overlap guard for in-progress bars
- Docker-ready with healthcheck endpoint

*Tech: FastAPI · Python · PostgreSQL · Docker · KuCoin API · Webhooks*

---

### [n8n Torob Scraper](https://github.com/Amirezamky9/n8n-torob-scraper)

**E-commerce price monitoring workflow** for Persian marketplaces — scrapes product listings and prices from torob.com using a two-pass strategy.

- Pass 1: scrape shop/category pages to collect product links
- Pass 2: visit each product page for price comparisons across sellers
- **No API keys required** — pure HTTP + HTML/CSS selector parsing
- Smart link filtering and batch looping with delays

*Tech: n8n · Web Scraping · HTML Parsing · CSS Selectors*
