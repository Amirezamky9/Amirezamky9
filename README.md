### ₿ Crypto Ingestion Pipeline

> **Problem:** Needed a reliable, on-demand service to fetch KuCoin OHLCV data into PostgreSQL.

**Solution:** A FastAPI webhook-triggered ingestion service with smart delta + backfill cycle.

<details>
<summary><b>⚡ Technical Details</b></summary>

- FastAPI backend with Bearer token auth
- Smart delta strategy — only fetches new data since last candle
- Zero DDL — `INSERT ... ON CONFLICT DO UPDATE`
- Zero disk logs — streams to external webhook
- Exponential backoff retry (timeouts, 429, 5xx)
- Docker-ready with healthcheck endpoint

</details>

`FastAPI` · `Python` · `PostgreSQL` · `Docker` · `KuCoin API` · `Webhooks`

### 🛒 n8n Torob Scraper

> **Problem:** Needed automated price monitoring for Persian e-commerce products without APIs.

**Solution:** An n8n workflow using a two-pass strategy — collect links from categories, then scrape seller-level pricing.

<details>
<summary><b>⚡ Technical Details</b></summary>

- Two-pass scraping architecture in n8n
- Pure HTTP + HTML/CSS selector parsing
- Smart link filtering for product URLs
- Batch looping with configurable rate-limiting
- Price comparison across multiple sellers

</details>

`n8n` · `Web Scraping` · `HTML Parsing` · `CSS Selectors`
